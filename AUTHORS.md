# Authors and contributors

Vessel.js was created at the **Ship Design and Operation Lab**, Norwegian University of Science and Technology (NTNU), Ålesund, and developed between 2017 and 2025. It is now a legacy project and is no longer actively maintained.

The library was introduced in Gaspar (2018), and its later state was described in Gaspar (2022). See [How to cite](README.md#how-to-cite).

## People

The roles and periods below come from the git history. Commit counts leave out merge commits.

| Contributor | Period | Main contributions |
|---|---|---|
| **Henrique Murilo Gaspar** | 2017–2025 | Conceived and led the project. Author of the IMDC 2018 and IMDC 2022 papers. Worked on core classes, example data and the website. |
| **Ícaro Aragão Fonseca** | 2017–2024 | Core developer. Worked on the object model (`source/classes`), ship specifications, 3D models, hull and stability calculations, and many examples and snippets. Organized the repository and examples gallery. |
| **Felipe Ferrari de Oliveira** | 2018–2025 | Main later developer. Wrote the ES-module version (`source/jsm`), the build pipeline, the 3D engine, and the manoeuvring, simulator, Trondheim and OpenBridge examples. Also wrote the Observable notebooks and the current website. |
| **Elias Hasle** | 2017–2019 | Early core developer. Worked on core classes and functions, the hull calculations and vector utilities, the file-browsing utilities, and early examples and apps. |
| **Diogo Kramel** | 2019 | Dynamic simulations with mooring lines (including parametric mooring), ship specifications and example data. |
| **Vicente Alejandro Iváñez Encinas** | 2017–2018 | Stability examples (GM, GZ curve), block-case comparison, top-down vs. bottom-up and cruise ship examples. |
| **Mateus Sant'Ana** | 2017 | Early prototypes, DP library figures and wiki material. |
| **Sergi Escamilla** | 2019 | Multibody examples. |

Other students and colleagues at NTNU contributed case studies, data and feedback through theses and courses.
