About

Vessel.js is an open-source JavaScript library for conceptual ship design, developed from 2017 to 2025 at the Ship Design and Operation Lab, Norwegian University of Science and Technology (NTNU) in Ålesund. The ship is represented as an object and used for hydrostatics, stability, motions, marine operations and manoeuvring simulations directly in the web browser. The library is no longer actively maintained and is kept online as a reference for research and teaching.

Introduction

Vessel.js is a JavaScript library for conceptual ship design with an object-oriented paradigm. Vessel.js represents the vessel as an object, which is used to simulate different functionalities and behaviors. Currently, the library includes methods for hydrostatic, dynamics and stability calculations.

The library is developed by Ship Design and Operation Lab at Norwegian University of Science and Technology (NTNU) in Ålesund.

Download the latest version here:

  • vesseljs.zip

Import Vessel.js in html by using the following script:

import * as Vessel from "../build/vessel.module.js"

How to cite

Vessel.js was introduced and explained in the IMDC 2018 paper, and its later state was documented at IMDC 2022. If you use the library or its examples, please cite:

  • Gaspar, H. M. (2018). Vessel.js: An open and collaborative ship design object-oriented library. In Marine Design XIII – Proceedings of the 13th International Marine Design Conference (IMDC 2018), Helsinki, Finland. CRC Press. https://doi.org/10.1201/9780429440533-10
  • Gaspar, H. M. (2022). Current State of the Vessel.js Library: A Web-Based Toolbox for Maritime Simulations. 14th International Marine Design Conference (IMDC 2022), Vancouver, Canada. SNAME. https://doi.org/10.5957/IMDC-2022-271

BibTeX entries are available in the README and in CITATION.cff.

Status

Vessel.js is a legacy project and is no longer under active development. The code, examples and this website are kept online as a reference. You are welcome to fork the repository for your own work.

You are also welcome to create issues reporting bugs or suggesting improvements, but they may not be addressed.
